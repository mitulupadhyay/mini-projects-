# Simon Says Game

A browser-based memory game built using HTML, CSS, and Vanilla JavaScript.

## Features

- Random color sequence generation
- Increasing difficulty with each level
- User input validation
- Game over detection
- Score tracking
- Game restart functionality
- Button animations and visual feedback

## Tech Stack

- HTML5
- CSS3
- JavaScript

## How to Play

1. Press any key to start the game.
2. Watch the sequence of flashing buttons.
3. Click the buttons in the same order.
4. Each successful round adds another color to the sequence.
5. One wrong click ends the game.
6. Press any key to restart.
